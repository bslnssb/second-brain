# 公开仓库内容清单（唯一权威）
#
# 这个文件回答一个问题：**release/github 里到底该有什么**。
# 下次发版不要再凭记忆判断，跑 `python tools/sync_public.py` 和 `python tools/check_public.py`：
#   清单里有、源目录有  → 同步过去
#   清单里有、源目录没有 → 报错（改名或删了源文件，得改清单）
#   仓库里有、清单里没有 → 报错（有人手滑放进来的东西）
#
# 三种前缀：
#   sync  从开发根（../../）同步过来；开发根是唯一维护地
#   local 只在这个仓库里维护，开发根没有（构建脚本、仓库自己的图标、CI 配置）
#   build 构建产物，由 `npm run build` 生成在开发根 web/dist，同步过来；不进 git
#
# 目录以 / 结尾 = 整个子树。
# 被 .gitignore 排除的东西（node_modules、dist、build、*.log）不用写在这里。
