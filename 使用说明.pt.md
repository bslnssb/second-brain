# Second Brain · Guia do usuário (Português, v0.9)

> Este é o guia rápido traduzido. A referência completa em chinês está em [`使用说明.md`](使用说明.md).

## O que é

Um buscador de arquivos **local** para Windows: indexa os nomes de todos os arquivos do disco e o texto dentro dos documentos (PDF, Word, Excel, PowerPoint, texto, Markdown, CSV, EPUB, páginas digitalizadas via OCR e formatos antigos `.doc/.xls/.ppt/.wps` através do Office/WPS COM).

Tudo fica na sua máquina. Sem conta, sem envio, sem telemetria.

## Instalação

Execute `SecondBrain-Setup-v0.9.x.exe`.

- Escolha a pasta de instalação (padrão `%LOCALAPPDATA%\SecondBrain\App`).
- Escolha o **idioma do app** (中文 / English / Español / Português / हिन्दी) — o programa abre nesse idioma na primeira vez.
- Um atalho é criado na área de trabalho; não precisa de administrador.

## Primeira execução

Ele se configura sozinho: pega Área de Trabalho / Documentos / Downloads, começa a indexar e **em ~3 segundos você já pode buscar nomes de arquivo**. O texto dos documentos é lido em segundo plano — o rodapé mostra quantos já foram. Aparece um cartão explicando o essencial (Ctrl duplo, menu de contexto) e não incomoda mais.

## Buscar

Digite qualquer coisa: nome de arquivo, de pasta ou uma palavra dentro de um documento.

| Você digita | Você obtém |
|---|---|
| `微信` | arquivos e pastas com esse nome, e documentos que o contêm |
| `ext:pdf 合同` | somente PDF |
| `size:>10m` | arquivos acima de 10 MB (também `1k-2m`) |
| `dm:7d` | modificados nos últimos 7 dias (`2w`, `1m`, `1y`) |
| `-草稿` | exclui o que tiver essa palavra no caminho |
| `网安学习/` | somente essa pasta (barra no fim) |
| `content:发票` | só texto de documentos, ignora nomes |

O seletor `Tudo / Nome / Conteúdo` faz o mesmo sem sintaxe.

## Teclado

| Tecla | Ação |
|---|---|
| `↑` `↓` | selecionar |
| `Enter` | abrir |
| `Ctrl+Enter` | mostrar na pasta |
| `Ctrl+1` … `Ctrl+9` | abrir o resultado N |
| `Ctrl+S` | alternar ordenação (relevância / recente / antigo / maior / nome) |
| `Ctrl+F` | ir para a busca |
| `Esc` | limpar / fechar painel |
| `Ctrl` duas vezes | abrir a janela mini de qualquer lugar |

## Bandeja e ajustes

- **Ajustes** (engrenagem): iniciar com o Windows, atalho Ctrl duplo, tema, idioma, escopo do índice, ferramentas de manutenção (escanear, atualizar, reconstruir nomes, autodiagnóstico).
- **Bandeja**: busca detalhada · busca mini · ajustes · sobre · ajuda · comentários · sair.
- Fechar a janela apenas a esconde — o programa continua na bandeja. Para sair, use o menu da bandeja.

## Atualizações

**Sobre → Verificar atualizações.** Ele tenta vários espelhos (jsDelivr, gitmirror, raw.githubusercontent, GitHub API) porque o GitHub nem sempre é acessível. Se houver versão nova, dá para baixar e instalar no lugar; o banco e as configurações são mantidos.

## Onde ficam os dados

Tudo junto ao programa (ou em `%LOCALAPPDATA%\SecondBrain\data` se a pasta for somente leitura):

- `brain.db` — o índice (nomes + texto)
- `scope.json` — quais pastas são indexadas
- `settings.json` — tema, idioma, atalhos
- `apps.json` — suas escolhas “fixar no topo / ocultar entrada”

Para mover: feche o programa, copie a pasta inteira e execute o exe lá.

Para desinstalar: apague a pasta.

## Privacidade

Sem chamadas de rede, exceto a verificação de atualizações e o canal de avisos. O índice nunca sai da sua máquina.

## Limites conhecidos

- Em **PDF digitalizados** o texto vem de OCR (6 primeiras páginas, 20 por rodada): letra à mão ou borrada pode falhar.
- `.doc/.xls/.ppt/.wps` antigos exigem Office ou WPS; sem eles, só busca por nome.
- Pastas não têm “conteúdo”, só nome e data.
- A busca `content:` com duas letras olha um trecho recente para continuar rápida; um documento recém-salvo pode levar alguns segundos para aparecer por esse caminho.
