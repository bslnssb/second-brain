# Second Brain · User Guide (English, v0.9)

> This is the translated quick guide. The exhaustive Chinese reference is [`使用说明.md`](使用说明.md).

## What it is

A **local** file search for Windows: it indexes file names across your whole disk, and the text inside documents (PDF, Word, Excel, PowerPoint, text, Markdown, CSV, EPUB, scanned pages via OCR, and legacy `.doc/.xls/.ppt/.wps` through Office/WPS COM).

Everything stays on your machine. No account, no upload, no telemetry.

## Install

Run `SecondBrain-Setup-v0.9.x.exe`.

- Choose the install folder (default `%LOCALAPPDATA%\SecondBrain\App`).
- Choose **App language** (中文 / English / Español / Português / हिन्दी) — the program starts in that language the first time.
- A desktop shortcut is created; the program does not need administrator rights.

## First start

It configures itself: it picks Desktop / Documents / Downloads, starts indexing, and **within ~3 seconds you can already search file names**. Document text is read in the background — the footer shows how many documents are done. A card explains the two things worth knowing (double Ctrl, right-click actions), then never bothers you again.

## Searching

Type anything: a file name, a folder name, or a word from inside a document.

| You type | You get |
|---|---|
| `微信` | files and folders with that name, plus documents containing the word |
| `ext:pdf 合同` | only PDFs |
| `size:>10m` | files bigger than 10 MB (`1k-2m` also works) |
| `dm:7d` | modified in the last 7 days (`2w`, `1m`, `1y`) |
| `-草稿` | exclude anything whose path contains this |
| `网安学习/` | only this folder (trailing slash) |
| `content:发票` | document text only, ignore file names |

The `全部 / 文件名 / 正文` switch above the list does the same thing without syntax.

## Keyboard

| Key | Action |
|---|---|
| `↑` `↓` | select |
| `Enter` | open |
| `Ctrl+Enter` | reveal in folder |
| `Ctrl+1` … `Ctrl+9` | open result #N |
| `Ctrl+S` | cycle sort (relevance / newest / oldest / largest / name) |
| `Ctrl+F` | focus the search box |
| `Esc` | clear search / close panel |
| double `Ctrl` | summon the mini search window from anywhere |

## Tray and settings

- **Settings** (gear icon): start with Windows, double-Ctrl hotkey, theme, interface language, index scope, maintenance tools (scan, update, rebuild names, self-check).
- **Tray**: Open detailed search · Mini search · Settings · About · Help · Feedback · Quit.
- Closing the window only hides it — the program keeps running in the tray. Quit from the tray menu.

## Updating

**About → Check for updates.** It tries several mirrors (jsDelivr, gitmirror, raw.githubusercontent, GitHub API) because GitHub is not always reachable. If a newer version exists you can download and install it in place; your database and settings are kept.

## Where the data lives

Everything sits next to the program (or in `%LOCALAPPDATA%\SecondBrain\data` if the program folder is read-only):

- `brain.db` — the index (names + document text)
- `scope.json` — which folders are indexed
- `settings.json` — theme, language, hotkeys
- `apps.json` — your “pin to top / hide this entry” choices

To move to another disk: quit the program, copy the whole folder, run the exe there.

To uninstall: delete the folder. That's it.

## Privacy

No network calls except the optional update check and the announcement feed. The index never leaves your machine.

## Known limits

- Inside **scanned PDFs** text is recognised by OCR (first 6 pages, up to 20 per run) — handwriting and blurry scans may be missed.
- Legacy `.doc/.xls/.ppt/.wps` need Microsoft Office or WPS installed; without it those files are searchable by name only.
- Folders have no “content”, only names and modification time.
- An empty `content:` search on a two-character word scans fewer rows to stay fast; very recent documents may take a few seconds to appear in that path.
