# Second Brain · Guía de uso (Español, v0.9)

> Esta es la guía rápida traducida. La referencia completa en chino está en [`使用说明.md`](使用说明.md).

## Qué es

Un buscador de archivos **local** para Windows: indexa los nombres de todos los archivos del disco y el texto dentro de los documentos (PDF, Word, Excel, PowerPoint, texto, Markdown, CSV, EPUB, páginas escaneadas con OCR y formatos antiguos `.doc/.xls/.ppt/.wps` mediante Office/WPS COM).

Todo se queda en tu equipo. Sin cuenta, sin subir nada, sin telemetría.

## Instalación

Ejecuta `SecondBrain-Setup-v0.9.x.exe`.

- Elige la carpeta de instalación (por defecto `%LOCALAPPDATA%\SecondBrain\App`).
- Elige el **idioma de la app** (中文 / English / Español / Português / हिन्दी): el programa arranca en ese idioma la primera vez.
- Se crea un acceso directo en el escritorio; no requiere permisos de administrador.

## Primer arranque

Se configura solo: toma Escritorio / Documentos / Descargas, empieza a indexar y **en unos 3 segundos ya puedes buscar nombres de archivo**. El texto de los documentos se lee en segundo plano — el pie de página muestra cuántos van. Aparece una tarjeta con lo esencial (Ctrl doble, menú contextual) y no vuelve a molestar.

## Buscar

Escribe cualquier cosa: un nombre de archivo, de carpeta o una palabra dentro de un documento.

| Escribes | Obtienes |
|---|---|
| `微信` | archivos y carpetas con ese nombre, y documentos que lo contienen |
| `ext:pdf 合同` | solo PDF |
| `size:>10m` | archivos de más de 10 MB (también `1k-2m`) |
| `dm:7d` | modificados en los últimos 7 días (`2w`, `1m`, `1y`) |
| `-草稿` | excluye lo que tenga esa palabra en la ruta |
| `网安学习/` | solo esa carpeta (barra final) |
| `content:发票` | solo texto de documentos, ignora nombres |

El conmutador `Todo / Nombre / Contenido` hace lo mismo sin sintaxis.

## Teclado

| Tecla | Acción |
|---|---|
| `↑` `↓` | seleccionar |
| `Enter` | abrir |
| `Ctrl+Enter` | mostrar en la carpeta |
| `Ctrl+1` … `Ctrl+9` | abrir el resultado N |
| `Ctrl+S` | cambiar orden (relevancia / reciente / antiguo / mayor / nombre) |
| `Ctrl+F` | ir al buscador |
| `Esc` | limpiar / cerrar panel |
| `Ctrl` dos veces | abrir la ventana mini desde cualquier lugar |

## Bandeja y ajustes

- **Ajustes** (engranaje): iniciar con Windows, atajo Ctrl doble, tema, idioma, alcance del índice, herramientas de mantenimiento (escanear, actualizar, reconstruir nombres, autodiagnóstico).
- **Bandeja**: búsqueda detallada · búsqueda mini · ajustes · acerca de · ayuda · comentarios · salir.
- Cerrar la ventana solo la oculta: el programa sigue en la bandeja. Para salir, usa el menú de la bandeja.

## Actualizaciones

**Acerca de → Buscar actualizaciones.** Prueba varios espejos (jsDelivr, gitmirror, raw.githubusercontent, GitHub API) porque GitHub no siempre es accesible. Si hay versión nueva puedes descargarla e instalarla en el sitio; la base de datos y los ajustes se conservan.

## Dónde están los datos

Todo junto al programa (o en `%LOCALAPPDATA%\SecondBrain\data` si la carpeta es de solo lectura):

- `brain.db` — el índice (nombres + texto)
- `scope.json` — qué carpetas se indexan
- `settings.json` — tema, idioma, atajos
- `apps.json` — tus elecciones “fijar arriba / ocultar entrada”

Para moverlo: cierra el programa, copia la carpeta entera y ejecuta el exe allí.

Para desinstalar: borra la carpeta.

## Privacidad

Sin llamadas de red salvo la comprobación de actualizaciones y el canal de avisos. El índice nunca sale de tu equipo.

## Límites conocidos

- En **PDF escaneados** el texto se reconoce por OCR (6 primeras páginas, 20 por pasada): la letra manuscrita o borrosa puede fallar.
- Los `.doc/.xls/.ppt/.wps` antiguos necesitan Office o WPS; sin ellos solo se buscan por nombre.
- Las carpetas no tienen “contenido”, solo nombre y fecha.
- La búsqueda `content:` de dos caracteres revisa un tramo reciente para mantenerse rápida; un documento recién guardado puede tardar unos segundos en aparecer por esa vía.
